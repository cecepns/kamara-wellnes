# Kamara Wellness by Akupunktur Banda Aceh
## Setup
1. `mysql -u root -p < backend/sql/database.sql`
2. `cd backend && cp .env.example .env && npm i && npm run dev` (port 5000)
3. `cd frontend && cp .env.example .env && npm i && npm run dev`
Login awal: **admin / admin123** (ganti segera). Reminder booking: dashboard menampilkan booking hari ini + tombol follow-up WhatsApp manual oleh admin.
